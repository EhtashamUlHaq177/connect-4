# Connect 4

A React-based Connect 4 game that demonstrates component-based UI and game logic.  
Built to practice state management, event handling, and win-detection logic.

## Tech Used
- React.js
- JavaScript
- CSS (external)

## Features
- Two-player gameplay (local, alternating turns)
- Also suggest button for computer player
- Winner detection logic
- Reset / New game functionality
- Clean component structure for learning and reuse
